# Support

## Where to ask

- **Bug:** open an issue with the bug report template.
- **Feature idea:** open an issue with the feature request template.
- **Usage question:** start a GitHub Discussion if Discussions are enabled.
  Otherwise, open an issue and label it as a question.
- **Security problem:** follow [SECURITY.md](SECURITY.md). Do not open a public
  issue.

## What to include

For an install or hook problem, include:

- Antigravity version;
- operating system;
- Python version (`python --version`);
- plugin version (`harness --version` or `harness doctor`);
- install method (one-prompt, manual, upgrade);
- the exact command or prompt that failed;
- relevant lines from `state/hook_errors.log`.

Do not paste a full transcript, API key, token, password, private path, or
customer data. Redact before posting.

## Response times

This is a small project. I read every report, but I cannot promise a same-day
response. Security reports are prioritized. See [SECURITY.md](SECURITY.md) for
the security timeline.

## Before you ask

1. Run `harness doctor`.
2. Check [INSTALL.md](INSTALL.md#troubleshooting).
3. Check [docs/FAQ.md](docs/FAQ.md).
4. Search existing issues.
